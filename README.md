# Reweighing for Bias Mitigation – Data Wrangling Assignment 4
Evaluation of the Reweighing pre-processing algorithm (Calders, Kamiran & Pechenizkiy, 2009)

## How to run
1. Python 3.9 or newer.
2. Install the packages:
   pip install aif360 scikit-learn pandas numpy
3. Open `A4_bias-mitigation.ipynb` and run all cells from top to bottom.
   The first data cell downloads the raw dataset files into AIF360's data folder
   automatically (internet needed the first time).
